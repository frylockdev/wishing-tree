# Спека: кликабельный MVP «Сад Выгоды»

Дата: 2026-07-24 · Статус: утверждена пользователем

## Цель

Кликабельный MVP фермерской мини-игры «Сад Выгоды» (по GDD v1.0 из `documents/`) для демонстрации core loop. Без реального бэкенда: вся серверная логика эмулируется моковым API-слоем. Полный демо-сценарий (саженец → урожай → купон) проходится за пару минут.

## Стек

- Phaser 3 + TypeScript + Vite.
- Гибридный UI: Phaser-canvas для игровых сцен (сад, колесо), HTML/CSS-оверлеи на чистом TS для списочных экранов.
- Целевой вьюпорт: портрет 360×640; на десктопе — «телефонная» рамка по центру, на мобильном — фулскрин. Проверяется в браузере на десктопе и на телефоне по локальной сети.
- Язык интерфейса — русский, тексты хардкодом.

## Архитектура

```
src/
  game/      — Phaser-сцены: BootScene, GardenScene, WheelScene
  ui/        — HTML-оверлеи: онбординг, задания, награды, друзья, альбом, купон-модалка, дев-панель
  api/       — интерфейс ApiClient + MockApiClient (вся экономика, in-memory + localStorage, задержка 150–400 мс)
  state/     — стор состояния игрока + шина событий (pub/sub)
  config/    — числа экономики (демо-пресет + реальный пресет из GDD рядом), брендовые темы
```

Правила потока данных: UI и сцены зовут только `ApiClient`; тот меняет состояние в сторе; стор рассылает события; сцены и оверлеи подписаны и перерисовываются. Никто не мутирует состояние напрямую.

`ApiClient` — интерфейс с методами как у будущего REST API: `getState`, `water`, `harvest`, `claimDailyBonus`, `completeTask`, `spinWheel`, `exchangeReward`, `helpFriend`, `scanReceipt`, `openChest`, `selectSapling`, `resetProgress`. При появлении реального бэка меняется только реализация.

## Брендовые темы

Два скина на одной кодовой базе: «Пятёрочка» (яблоня, красная гамма) и «Перекрёсток» (груша, зелёная гамма). Тема = объект конфига: палитра, названия, набор ассетов (фон, стадии дерева, фрукт). Выбор при первом запуске, смена — в дев-панели.

## Механики MVP

- **Онбординг**: 3 подсказки + выбор саженца → первый полив в обучении.
- **Сад (90% времени)**: дерево, счётчики капель/монет/урожая, кнопка «Полить» (10 капель = 1 полив = 10 очков роста), прогресс-бар стадии, частицы воды, тряска дерева.
- **5 стадий роста** с наградами за переход (по GDD: монеты, купон −5%). Демо-тайминги: полный цикл ~15–20 поливов. Реальные цифры GDD лежат в конфиге вторым пресетом.
- **Сбор урожая**: 800–1200 фруктов, анимация разлёта, дерево уходит в альбом, выбор нового саженца.
- **Ежедневный вход и стрик**: бонус капель растёт по серии дней, день 7 — удобрение (×2 очков роста на «сутки»).
- **Задания** daily/weekly из GDD с прогрессом и наградами; «Сканируй чек» — мок-экран, начисляет 1 каплю / 10 ₽ рандомной суммы (лимит 2/день).
- **Колесо удачи**: Phaser-сцена с анимацией вращения; сектора из GDD (капли, монеты, удобрение, купон −3%, джекпот −15% с шансом 0,5%); 1 бесплатное вращение в день, доп. — за 50 монет.
- **Сундук с таймером**: раз в 4 «часа» виртуального времени, 10–30 капель.
- **Друзья (мок)**: фиксированный список фейковых друзей с деревьями разных стадий; «Помочь полить» — +5 капель себе (лимит 10/день); рейтинг недели.
- **Витрина наград**: каталог из GDD (купоны, продукт СТМ, баллы, партнёрка); при обмене — модалка купона с фейковым штрихкодом, промокодом и сроком действия; история обменов.
- **Альбом сада**: собранные деревья по циклам.

## Виртуальное время

Сервис игровых часов. Кнопка «Новый день» в дев-панели: пересчёт стрика, сброс daily-заданий и лимитов, обновление колеса и сундука. Сундук привязан к виртуальным часам («+4 часа» тоже в дев-панели).

## Дев-панель

Скрытая (тройной тап по логотипу или клавиша `~`): +100 капель, +500 урожая, «Новый день», «+4 часа», смена скина, сброс прогресса.

## Персистентность

Всё состояние — в localStorage через MockApiClient. Кнопка сброса в дев-панели.

## Арт

ИИ-генерация в едином мягком мультяшном стиле: фон сада с магазином (2 версии), 5 стадий дерева × 2 фрукта, маскот-ёжик, иконки валют, колесо удачи, фрукты для частиц.

## Вне скоупа

Реальный бэкенд, авторизация и карта лояльности, настоящие пуши, антифрод, кража капель, командные грядки, сезонные события, JS-bridge с нативным приложением, i18n.
